独立用 pdfplumber 提取全 PDF 原始文字层，将其英文词多重集合与 Document 的正文词逐词比对：去除不计入正文的两词标题 Lexicon Quest 后，完全一致。该检查验证未丢失或重复英文正文词；不等同于任意版面都已完美还原。

样本空格被编码为 U+0001，已转空格；不可见符和多空格被清理。末尾单独的 & 被移除，原注释保留。A.M./A.D./B.C. 未被误切，图片成为页末独立引用，不打断段落。对页底未结束、下一页以小写开始的段落做保守跨页合并，其他情况仍可能需要人工调整。

原文没有独立标注完整的 312 个目标词，所以未将“候选词”冒充为正式清单，也没有报告虚构的 312/312。导入自己的清单后即可计算真实覆盖率。

复现：

```sh
python tools/check_lexicon.py "词汇探秘之旅-原文7601200994240873450.pdf"
```

脚本会验证上述样本的已知词频、缩写、复合词、特殊空格、原文例句/搭配及逐词一致性，并把正文、候选分析、9 词核对报告/JSON 和 verification.json 放在 output/lexicon_check/。
